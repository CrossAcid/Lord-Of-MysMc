# 秘闻之径 / Whisperway

## 项目定位

一款融合克苏鲁式宇宙恐怖、神秘学奇幻、传统西幻、桌面角色扮演式冒险、中式志怪、怪物狩猎与开放世界委托体验的 Minecraft 角色扮演整合包。项目以**序列养成、战斗、探索和任务**为主要体验，以制作、经济、职业、图鉴和知识等系统丰富世界与角色成长。

项目吸收《诡秘之主》等作品的类型和结构灵感，但不复刻其中的怪物、途径、能力、物品、人物与剧情。具体世界、序列、任务和美术均采用原创设计。

首批内容以中世纪黑暗奇幻为主，围绕骑士、法师、神秘学与冒险展开；中式志怪和古代国风道路留待后续地区扩展。

核心 Mod 标识为 `whisperway`，Java 根包为 `io.github.crossacid.whisperway`。

技术版本：**Minecraft Java 1.21.1 + NeoForge 21.1.250 + 64 位 JDK 21**，构建工具为 Gradle 9.2.1、ModDevGradle 2.0.147。开发环境已经跑通，玩法尚处于原型阶段。

开发工程位于 `core/`。在该目录执行 `./gradlew.bat build` 构建，执行 `./gradlew.bat runClient` 启动开发客户端（Windows PowerShell）。

`core/` 是当前唯一的自研 Mod，也是将来其他模块依赖的核心。大部分玩法可以放在同一个 JAR 中；只有需要独立安装、独立发布或隔离可选依赖时，才增加新的 Gradle 子项目。整合包配置和资源包将来分别放入 `pack/` 与 `resourcepacks/`。

## 核心循环

| 方向 | 主要内容 |
| --- | --- |
| 养成 | 发展原创序列、完成晋升考验、学习职业并构建能力与装备搭配 |
| 战斗 | 组合基础属性、武器、序列技能、特殊物品、环境与战术应对敌人 |
| 探索 | 发现地区、遗迹、怪物和异常事件，获得材料、装备、线索与故事 |
| 任务与生活 | 完成委托和原创剧情，通过职业、交易、炼药和制作建立人脉与经济基础 |

主要流程：**接受委托 → 探索与调查 → 战斗或解决事件 → 获得报酬和材料 → 制作装备或完成晋升 → 解锁新的任务与区域**。

知识系统是其中一项辅助机制：阅读、观察和实战发现可以补充图鉴、揭示弱点或提供任务解法，但不会取代战斗、探索、成长和剧情本身。

## 内容与实现原则

- 原作和其他奇幻作品提供类型灵感，最终世界规则和内容由项目创作。
- 所有机制以 Minecraft 的操作、节奏、探索和联机体验为设计依据。
- **自研 Mod**负责序列、战斗、任务、怪物、物品、职业、经济、图鉴、知识、存档和联机逻辑。
- **资源包**负责贴图、模型、界面和音效；美术资源采用原创内容或许可清楚的素材。
- **整合包配置与第三方 Mod**补充任务、探索及配套功能，待原型需求稳定后选择。

## 第一阶段

先做通铁卫从普通人晋升序列 9“持剑侍从”的完整体验：角色与能力底层、随消化成长的属性、战势、反击重斩、阻碍地形适应与护卫委托优势、一处小型探索区域、一份委托、一种原创怪物、一份晋升药剂和一件特殊物品。

完成闭环并通过独立服务端验证后，再决定序列 8 以及烛灵、歧路的具体能力；职业、经济、完整图鉴、高序列和其他维度随后扩展。美术先满足原型需求，所有玩法状态需要能够保存并由服务端正确判定。

## 素材与发布边界

剧情、文本和美术采用原创内容，外部素材遵守各自许可；Wiki 仅用于理解和查证，文字和图片不能直接搬用。第三方 Mod 必须核对整合包再分发规则。

原创内容和免费发布本身不能消除全部权利风险。公开发布前应依据最终采用的名称、设定表达、素材和第三方 Mod 再做一次完整检查。
