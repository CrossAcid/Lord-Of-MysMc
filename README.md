# 诡秘世界观 Minecraft 角色扮演整合包

## 项目定位

基于《诡秘之主》世界观，以序列晋升为内核，结合原创角色与剧情，围绕**养成、战斗、探索**展开。参考范围包括《诡秘之主》和《宿命之环》，按玩法需要选用原作设定，不以完整复刻原著为目标。

技术版本已确定：**Minecraft Java 1.21.1 + NeoForge 21.1.250 + 64 位 JDK 21**，构建工具为 Gradle 9.2.1、ModDevGradle 2.0.147。计划免费公开发布；目前已跑通示例 Mod 的构建、客户端启动及单人世界，玩法开发尚未开始。

开发工程位于 `core/`。在该目录执行 `./gradlew.bat build` 构建，执行 `./gradlew.bat runClient` 启动开发客户端（Windows PowerShell）。当天成果和后续事项记录在[开发进度](docs/progress.md)。

## 核心玩法

| 方向 | 主要内容 |
| --- | --- |
| 养成 | 选择途径、收集魔药材料、扮演消化、完成晋升条件、构建能力与装备搭配 |
| 战斗 | 突出不同途径的能力特色，通过情报、准备、技能和非凡物品应对敌人，同时承担消耗与风险 |
| 探索 | 调查异常、发现地点与秘密、获得配方和材料，解锁原创事件与任务 |

建议的主要流程：**探索与调查 → 获取知识和材料 → 获得并运用能力 → 扮演消化 → 完成晋升条件 → 挑战新的区域与敌人**。

原创剧情围绕玩家的成长与选择展开，把线索、事件和人物关系融入上述流程。具体角色、故事、地区和任务尚待设计。

## 内容与实现原则

- 原作提供世界规则和力量体系基础；角色、对白、剧情与具体冒险由项目创作。
- 为 MC 的操作、节奏和联机体验调整能力与条件，明确哪些是项目改编。
- **自研 Mod**负责序列、能力、魔药、消化、失控、非凡物品及存档和联机逻辑。
- **资源包**负责贴图、模型、界面和音效；基础资源可随 Mod 发布，独立资源包用于主题覆盖。
- **整合包配置与第三方 Mod**补充任务、探索及其他配套功能，按需要选取；当前不锁定模组清单。

## 第一阶段建议

先选一条途径，做通从普通人到首次晋升的完整体验：一个原创任务区域、一组调查与战斗事件、材料和魔药、基础技能、扮演消化与下一阶段晋升。起始途径和序列上限尚未确定。

先验证这段流程是否有趣，再逐步扩展途径、非凡物品和探索内容。美术先满足原型需求，玩法状态需要能够保存并支持联机。

## 素材与发布边界

剧情、文本和美术优先原创，外部素材遵守各自许可；Wiki 用于查证，文字和图片不能默认直接搬用。遵守 Minecraft 与第三方 Mod 的分发规则。

当前不安排授权申请流程。原创剧情和免费发布并不能单独证明无需许可；保留原作具体设定的使用是否涉及改编等权利，要结合最终内容判断，公开发布前再核查。依据：[《著作权法》第十、十三、二十四条](https://www.luoding.gov.cn/ldsrmzf/zwgk/ztzl/zdlyxxgkzl/lyscjgzfxxgk/cyzl/content/mpost_1525009.html)、[Minecraft 使用指南](https://www.minecraft.net/zh-hans/usage-guidelines)。
