# 原创途径草案：铁卫、烛灵、歧路

日期：2026-09-18。状态：**首批中世纪黑暗奇幻风格及铁卫、烛灵、歧路三个方向已认可；具体阶位、能力细节与数值仍为草案，尚未实现。**

先比较 22 条原作途径的设计结构，再提出三条原创道路。首批采用中世纪黑暗奇幻风格：重甲骑士、提灯术士与行走歧路的冒险者。中国风途径留待后续地区扩展。三条覆盖持续近战、施法与召唤、机会与取舍；最终目标暂定为18条，当前先验证少量低序列玩法。

## 2. 从参考到原创的设计原则

1. **先确定力量为何存在，再安排技能。** 同一主题要同时解释攻击、生活用途、弱点和仪式；高序列扩大作用对象与范围，而不是随意拼入别人的能力。
2. **战斗身份从序列 9 就成立。** 战士起步就能近战，法师起步就能施法，机会型道路起步就有可感知的好运，不让玩家等待数个阶段才玩到主题。
3. **每次晋升存在改变。** 解锁新机制，新代价，新能力等，不只是获得更高数值；旧能力仍然有用。
4. **代价提供选择。** 允许常规、安全地使用能力；主动超限才进入显著风险。避免每次施法都罚站，或无预警永久摧毁角色。
5. **仪式回答该阶段的力量难题。** 先实践“怎样承受而不崩溃”“怎样造形而不迷失”“怎样取舍而不贪求”，然后获得对应能力。
6. **多途径互补。** 治疗、炼金、梦境、追猎、誓约、兽化、机巧、镇邪等保留独立空间，不让前三条覆盖所有职业。
7. **先写 Minecraft 交互，再写叙事解释。** 每项能力必须对应属性、攻击、格挡、状态、实体、方块、物品栏、配方或任务条件；“托住建筑”“完成救灾”等无法稳定判定的描述不能单独成为技能。
8. **非战斗能力必须改变规则。** 其他角色也能完成的普通动作不算途径特色；地形适应、委托门槛降低、特殊交互或额外任务选项才算实际优势。

### 共用成长规则（项目提案）

- 普通人 → 序列 9：完成入门委托、取得特性与药剂，在安全地点完成启途。
- 序列 9～7 为低序列，6～5 为中序列，4～1 为高序列，0 为终局权柄。数值与内容分阶段实现。
- 晋升需要：**当前魔药消化完成 + 下一阶材料和药剂 + 身心状态稳定 + 达到需要时完成仪式**。
- 服药后先获得该序列的基础能力；消化达到 25%、50%、75% 和 100% 时逐步提高属性或完善能力效果。完全消化才获得该序列的最终数值，并取得晋升下一序列的资格。
- 从 **6 → 5** 开始，每次晋升有专属仪式。9 → 8 → 7 → 6 通过实践、材料和简短成长任务推进，不堆砌大型仪式。
- 有效战斗、探索与委托提供基础消化；符合途径原则的行为额外加速。行为必须解决真实问题，训练可提供有上限的基础进度；
- 不设跨途径的强制读书、收集知识点门槛。相关书籍可以提示实践方法、材料线索和仪式含义。
- 仪式允许单人完成，也允许 NPC 或玩家协作；关键个人行为必须由晋升者完成。失败可准备后重试，事前说明消耗和风险，不设置现实数月等待。
- 仪式先以当前阶位能力配合工具、场地和任务装置完成象征性实践，再解锁下一阶能力；玩家不能提前施展尚未获得的技能。
- 序列 0 是远期内容方向，非首版承诺；多人服不照搬“全服只能有一个玩家晋升”的稀缺席位。

## 4. 铁卫途径

**力量主题：承载、卸力、回击。** 从能站稳的持械者，成长为替一片战场承受冲击的存在。视觉采用磨损板甲、塔盾、长剑和带裂痕的纹章；力量由武器和肉身发挥。

### 操作、代价与实践

- 首版只加入一种自定义战斗资源：**战势**。此前设想的“承压负荷”暂不实现，避免与生命、护甲、盾牌耐久、冷却同时形成过多状态条；以后只有在试玩证明有必要时再加入。
- 近战命中提供少量战势，盾牌成功挡住有威胁的攻击提供更多战势。战势脱战后衰减，不能通过攻击盔甲架、友军或无威胁生物获取。
- 反击重斩是明确的按键技能：消耗战势强化下一次近战攻击，产生短距离扇形伤害和击退。地形效果只作用于 `whisperway:impact_breakable` 标签中的脆弱方块，不破坏容器、方块实体、领地保护区域，并受配置项控制。
- 铁卫的力量通过最大生命、近战伤害、护甲韧性、抗击退和移动效率等明确属性体现，不建立会影响挖掘、跳跃等所有行为的通用“力量值”，也不额外扩展物品栏。
- 喝下魔药时只获得初步力量；属性和反击重斩在 0%、25%、50%、75%、100% 消化里程碑逐步增强。完整数值见[序列 9 原型规格](序列设定/铁卫/序列9-持剑侍从.md)。
- 护卫优势通过任务系统实现：铁卫可以越过部分委托经验门槛，后续阶位还能标记护卫目标、显示袭击方向或提供范围减伤。普通角色仍然可以完成护卫任务。
- 弱点是远程牵制、绕后、魔法与精神类伤害，以及举盾或重击造成的机动损失。高阶能力也必须表现为属性、状态、实体、范围或任务规则，不能依赖无法稳定判定的剧情动作。
- 加速消化的行为包括：击败对自身有威胁的近战敌人、有效格挡、保护护卫目标和完成护卫或防守委托。单纯携带重物、站着挨打或反复刷同一目标不提供进度。

### 晋升仪式

| 晋升 | 仪式提案 | 对应力量难题 |
| --- | --- | --- |
| 6 → 5 | 完成一场高难度护卫：在限定路线上保护任务 NPC，亲自格挡规定次数的有效攻击，并击败终点首领 | 既能承受攻击，也能把压力转化为反击 |
| 5 → 4 | 在不离开防守区域的条件下抵挡数轮进攻，保证核心旗帜没有被摧毁 | 从保护单一目标成长为守住据点 |
| 4 → 3 | 同时保护三个可被攻击的战旗锚点，在有限修复次数内完成波次与首领战 | 学会分配防守位置和资源 |
| 3 → 2 | 在事件首领战中保护场地核心，利用首领攻击打破指定事件障碍并最终击败它 | 驾驭大型敌人的力量，而非直接破坏世界 |
| 2 → 1 | 在持续施加远程、魔法和精神负面效果的防守事件中，维持护卫目标存活直到最后一波 | 面对自身短板仍维持防线 |
| 1 → 0 | 完成多阶段团队事件：依次激活并守住四个锚点，在最终首领阶段维持领域并完成最后一击 | 成为团队防线核心，但仍依赖阵地与队友 |
