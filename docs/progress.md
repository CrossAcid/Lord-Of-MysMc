# 开发进度与路线

最后更新：2026-09-19

当前阶段：**铁卫序列 9 纵向原型——基础数据与渐进属性已经跑通，下一步实现战势。**

## 当前结论

- 开发基线：Minecraft 1.21.1、NeoForge 21.1.250、JDK 21、Gradle 9.2.1。
- 项目名称：《秘闻之径 / Whisperway》；Mod ID 为 `whisperway`；Java 根包为 `io.github.crossacid.whisperway`。
- 第一段原型只制作“普通人 → 铁卫序列 9 → 战斗与消化”的纵向体验，暂不扩展其他途径和大型系统。
- 核心模组负责玩法与数值；Colorful Hearts 仅作为整合包的可选客户端显示模组，不成为核心代码依赖。

## 下一步：实现战势

按以下顺序逐步实现和测试：

1. 新增独立的服务端战势状态，并规定铁卫序列 9 的上限；战势不写入永久保存的 `PathwayProgress`。
2. 通过有效近战攻击和成功格挡获得战势，排除盔甲架、友军和无效刷取目标。
3. 定义战势的脱战衰减、死亡处理和切换途径时的清理规则。
4. 先用开发命令或聊天信息验证服务端计算，不立即制作 HUD。
5. 战势逻辑稳定后，再同步到客户端并绘制战势条。

完成标准：战势只能由有效战斗行为产生，数值不会越界，死亡、重进和清除途径时的行为符合设计。

## 第一段可玩闭环

- [ ] 一种有攻击前摇、弱点和有效掉落的原创怪物。
- [ ] 一处包含异常事件和晋升材料的小型探索地点。
- [ ] 一份能够接取、追踪、完成和结算的委托。
- [ ] 一件能提供不同解法、同时带有效果或代价的特殊物品。

完成标准：新角色能够在不使用开发命令的情况下完成“接取委托 → 探索与战斗 → 获得材料 → 晋升铁卫序列 9”。
