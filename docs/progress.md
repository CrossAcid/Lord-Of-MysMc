## 接下来的任务

严格按以下顺序推进。每个里程碑达到完成标准后再扩大范围。

### M1：角色与能力底层

- [x] 提出首版角色规则：沿用原版生命、护甲和饱食度；铁卫序列 9 只新增战势，不实现灵性或承压负荷条。数值仍待实测调整。
- [x] 确定技能输入与反馈方案：`G` 技能轮盘、鼠标选择、`R` 释放当前技能、`Z/X/C/V` 快捷技能槽；战势条位于生命与护甲区域上方。
- [ ] 建立服务端权威的玩家数据：途径、序列、消化度、已解锁能力和途径资源。
- [ ] 实现保存、重进世界恢复与客户端同步，并加入仅开发环境使用的测试命令。

完成标准：玩家状态可以保存和同步；单人重进世界不会丢失；客户端不能自行修改序列或资源。

### M2：铁卫普通人 → 序列 9

- [ ] 实现序列 9“持剑侍从”：有效近战与格挡积累战势，消耗战势发动反击重斩。
- [ ] 实现按 0%、25%、50%、75%、100% 消化里程碑成长的生命、近战伤害、护甲韧性、抗击退和移动效率。
- [ ] 实现受控地形破坏：只影响指定标签方块，遵守配置、领地保护且不影响容器。
- [ ] 战斗原型稳定后，实现护卫委托资格优势；普通职业和其他途径仍可通过正常经验或声望接取。
- [ ] 加入简单训练假人，用于练习攻击、积累战势和重斩；首次练习总计最多提供 10% 消化度，不制作专用训练场。
- [ ] 加入序列 9 晋升材料和药剂，并让消化度可成长至序列 8 临界点；暂不实现序列 8 晋升。
- [ ] 加入清楚的数值、音效和视觉反馈，屏蔽友军、盔甲架和无威胁目标刷取战势。

完成标准：从普通人取得序列 9、完成真实战斗、消化直到达到序列 8 临界点；退出重进后进度完整。

### M3：第一段可玩闭环

- [ ] 制作一种原创怪物，包含基础行为、明显攻击前摇、至少一种弱点和有用途的掉落。
- [ ] 制作一处小型探索区域，包含目标地点、晋升材料和一个异常事件。
- [ ] 制作一份委托，完成接取、追踪、战斗或调查、结算及报酬流程。
- [ ] 加入一件带明确效果或代价的特殊物品，使其在任务中提供另一种解法。

完成标准：新角色可以连续完成“接取委托 → 探索 → 战斗 → 获得材料 → 晋升序列 9”，不依赖开发命令。

### M4：工程与联机验证

- [ ] 验证世界重载、死亡、切换维度、独立服务端。
- [ ] 验证 GitHub Actions 构建，整理配置、日志和必要的服务端检查。
- [ ] 补充安装说明、已知问题和第三方许可清单，生成首个内部测试包。

完成标准：干净环境可以构建、安装并启动独立服务端。
