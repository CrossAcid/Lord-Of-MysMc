# 玩法设计总纲

## 项目支柱

《秘闻之径》的主要体验由四根支柱组成：

1. **序列养成**：选择原创道路，获得能力，承担代价并完成阶段晋升。
2. **人物战斗**：组合基础属性、序列技能、武器和特殊物品形成不同流派。
3. **世界探索**：进入城镇、荒野、遗迹和其他维度，发现怪物、资源与异常事件。
4. **任务与故事**：通过委托、人物关系和原创剧情赋予战斗与探索明确目的。

炼药、制作、经济、职业、图鉴、知识、伙伴和饮食是支撑这些体验的系统，不单独主导整个游戏。

## 核心循环

**接受委托 → 探索与调查 → 战斗或解决事件 → 获得报酬和材料 → 制作物品或完成晋升 → 解锁新的任务与区域**

同一事件可以通过战斗准备、序列能力、职业手段、物品、环境观察或特殊情报获得不同解法。原创剧情围绕玩家的成长与选择推进。

## 开发优先级

| 优先级 | 系统 | 目标 |
| --- | --- | --- |
| P0 核心 | 序列、角色状态、技能、战斗、怪物、探索、委托 | 形成可玩的 RPG 闭环 |
| P1 扩展 | 炼药、非凡物品、经济、职业、图鉴、知识 | 增加准备、成长和收集深度 |
| P2 丰富 | 宠物、信使、坐骑、多维世界、大型阵营剧情 | 扩展中后期内容和世界规模 |

优先级表示开发顺序，不表示系统在最终版本中的重要程度。P0 稳定前不批量铺设 P1、P2 内容。

## 原创序列与晋升

每条道路由若干序列阶位构成，但不采用原作途径名称、固定数量、技能或仪式。道路必须提供不同的操作方式，并在战斗之外具有至少一种用途。

设计一条道路时记录：

| 内容 | 要求 |
| --- | --- |
| 核心主题 | 擅长领域、玩法身份和主要弱点 |
| 主动能力 | 改变操作和战术，而不只是提高伤害 |
| 被动与代价 | 影响资源管理、环境适应或玩家决策 |
| 非战斗能力 | 用于探索、制作、交易、移动或任务 |
| 成长方式 | 说明玩家如何熟悉并稳定获得的力量 |
| 晋升条件 | 结合材料、挑战、任务和特殊条件 |

候选方向包括追猎与陷阱、炼金与元素反应、灵契与召唤、守誓与防护、梦境与感知、符箓与镇邪、机巧与造物、兽化与生存。先设计三条作为多样性样本，只实现其中一条的低阶内容。

## 战斗与角色

角色构筑由基础属性、武器动作、序列能力、状态效果、物品和环境共同决定。属性数量保持克制，只有能产生实际玩法差异的数值才加入。

首版需要解决生命、灵性或能力资源、冷却、伤害类型、状态效果和死亡处理。技能必须有清楚的视觉与声音反馈，并支持存档和多人同步。

怪物来自原创设计、传统西幻、民间传说和中式志怪灵感。每种怪物需要自己的行为、生态位置、战斗特点、掉落和视觉表达。

## 探索与世界

主世界由据点、城镇、荒野、遗迹和异常区域组成。探索奖励包括材料、装备、事件、人物、配方、线索和新任务，而不只是矿物数量提升。

其他维度用于承载不同规则和中后期挑战。只有当主世界的探索闭环稳定后才开始制作，并通过任务、晋升或特殊物品控制入口。

## 委托、职业与剧情

委托包括日常工作、调查、狩猎、护送、采集、异常事件和主线任务。任务应明确目标、风险、报酬与后果，并允许部分序列或职业产生额外解法。

日常职业用于赚钱、建立人脉和获得专业能力。候选职业包括药师学徒、猎人、商贩、厨师、矿工、抄写员、守卫和工匠。职业不锁死序列道路，玩家可以转职或发展副业。

剧情角色、组织、地区和事件全部原创。故事服务于玩家行动，避免长时间只阅读文本而没有探索、选择或战斗。

## 炼药、制作与物品

炼药由配方、材料处理、工具、步骤和品质构成。普通配方允许玩家制作；特殊物品可以要求专门设施、特定 NPC 或制作委托。

特殊物品由效果、消耗或代价、使用条件和获取方式组成。封印物应具有足够强的效果与明确风险，非凡特性可以用于晋升、制作和交易。

## 经济与交易

经济使用易读的原创货币。收入来自职业、委托、贸易、探索和制作；支出包括材料、装备、修理、情报、旅行、仪式和 NPC 服务。

关键晋升材料不能全部靠刷钱购买。价格和货源可以受到地区、供需、声望与任务进度影响，但首版只实现固定价格与基础买卖。

## 图鉴与知识

图鉴承担收集与信息查询功能，记录怪物、地点、材料、配方、物品和异常现象。条目可以通过阅读、观察、交谈、鉴定或实战逐步补全。

例如，野兽怕火这一信息可以来自书籍，也可以在玩家第一次用火攻击时记录。未知弱点依然正常生效，发现后图鉴提供清晰说明。知识可以带来情报、弱点提示或任务选项，但不会成为每场战斗和每次晋升的强制步骤。

只有少数涉及污染、禁忌或高阶秘密的知识具有危险代价。普通怪物资料和制作说明不必附加惩罚，避免系统喧宾夺主。

## 伙伴、信使与坐骑

伙伴可以参与战斗、侦察、携带物品或传递消息。信使承担远程交付和任务联络，坐骑服务于长距离探索。培养、装备和亲密度在核心玩法稳定后加入。

## 饮食

保留 Minecraft 正常饱食度，不增加营养、口渴等额外生存负担。特殊食物可以提供清楚、有限的临时效果或任务用途。

## 首个可玩原型

首个原型验证完整 RPG 流程：一条道路的首次晋升、两项可用能力、一处小型探索区域、一份委托、一种原创怪物、一份药剂和一件特殊物品。

玩家需要能够接取任务、探索目标区域、进行战斗、获得材料、完成晋升并保存成长。图鉴只加入一个简单条目，用于证明该系统将来可以接入，不作为原型完成的主要标准。
