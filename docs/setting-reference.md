# 设定与创作边界

## 项目定位

《秘闻之径 / Whisperway》是一款原创的黑暗奇幻 Minecraft 角色扮演整合包。创作灵感来自克苏鲁式宇宙恐怖、神秘学奇幻、传统西幻、桌面角色扮演式冒险、中式志怪、怪物狩猎与开放世界委托玩法。

首批地区、途径、物品与叙事以中世纪黑暗奇幻为主。古代国风可以作为后续地区的独立风格，不用于初始三条途径的主要命名、视觉和能力表现。

《诡秘之主》和《宿命之环》只作为结构灵感来源：世界存在隐秘力量、超凡成长伴随风险、知识具有价值和危险、物品可能同时具有能力与代价。项目不复刻原作故事和内容清单。

## 可以保留的设计思想

- **序列式成长**：每条道路由多个阶段构成，晋升需要知识、材料、实践和考验。
- **能力伴随风险**：强大能力会消耗资源，并可能造成污染、反噬或失控。
- **危险知识**：部分知识能改变探索、战斗或任务解法，少数高价值知识在获取时可能付出代价。
- **超凡物品体系**：普通超凡物品、带代价的封印物、可用于制作的超凡特性形成完整循环。
- **隐秘世界**：日常社会与超凡社会并存，玩家通过调查逐渐接触更深层的真相。
- **多层世界**：现实区域、特殊空间和其他维度共同承载探索与高阶内容。
- **宇宙恐怖**：世界之外存在难以理解的生命和规则；接触、崇拜或理解它们可能造成污染、认知变化与现实异常。

以上只规定玩法结构。具体名称、外观、配方、技能、晋升条件、组织、神祇、历史、地图、角色和剧情全部由项目原创。

知识只是世界构成的一部分，不是所有系统的统一资源或唯一门槛。项目的主要体验仍是序列养成、战斗、探索、委托和原创剧情。

## 必须原创的内容

- 怪物及其生态、弱点、掉落和故事背景。
- 全部晋升道路的名称、阶段、能力组合与考验。
- 非凡物品、封印物、材料、配方和负面效果。
- 人物、组织、阵营、宗教、地区、历史和世界事件。
- 任务、对白、书籍文本、谜题和剧情。
- 贴图、模型、界面、音乐、音效及宣传素材。

怪物可从公共领域的民间传说、传统西幻生物、中式志怪、宇宙恐怖和原创概念中获得灵感，但仍要制作项目自己的视觉设计、行为和文本。可以参考不可知的高位存在、禁忌知识、理智侵蚀、隐秘教团和非人尺度等类型思想；具体神祇、眷族、名称、标志、故事与美术使用原创内容。使用第三方模组或素材时，应单独记录作者、来源、许可证和整合包再分发条件。

“克苏鲁神话”由多位作者在不同时期共同扩展，不能假定所有相关作品、译文、游戏设定和美术都属于公共领域。资料使用时按具体作者、文本版本和素材来源分别核对。

## 设计检查

每项新内容进入开发前回答四个问题：

1. 它是否有自己的名称、视觉和背景？
2. 它的机制是否服务于 Minecraft，而不是复述小说段落？
3. 玩家能否仅通过本项目理解它，而不依赖原作知识？
4. 使用的文本、图片、声音、模型和代码是否为原创或已有明确许可？

若一项内容只能靠替换原作名称来显得不同，应重新设计其功能、获取过程和叙事位置。

## 资料使用方式

原作及用户提供的[灰机 Wiki](https://lom.huijiwiki.com/wiki/首页)仅用于理解类型和检查灵感来源。`22条序列原书设定/`保存带原网址的内部研究资料，与原创设计分开；新增文件优先记录结构化摘要和核对状态。公开仓库或发布包不得默认收录大段转载内容，提交前需要核对来源页面的署名、转载和许可要求，游戏内也不直接复制原作技能文本、配方、剧情或图片。

正式公开发布前，应再次检查项目名称、宣传文案、剧情文本、美术素材、第三方模组许可和 Minecraft 使用指南。当前文档是创作规范，不代替针对最终成品的法律意见。
