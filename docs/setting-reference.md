# 设定参考

资料范围：《诡秘之主》＋《宿命之环》。按实际玩法需要整理，重点是力量体系、非凡物品与世界规则；角色和剧情由项目原创设计。

## 核心设定

| 设定 | 开发时保留的要点 |
| --- | --- |
| 途径与序列 | 常规 22 途径各有序列 9 至 0，数字越小层次越高；各途径应有不同玩法 |
| 魔药与消化 | 获得力量和消化力量是不同阶段，晋升不能只依赖刷经验 |
| 扮演法 | 通过符合序列特征的行为与理解推进消化，融入探索、战斗和原创任务 |
| 灵性、污染与失控 | 能力具有消耗和风险；游戏中的具体数值、反馈与恢复方式由项目设计 |
| 晋升仪式 | 按具体序列核对要求，将适合的部分转化为探索和任务目标 |
| 相邻途径 | 转途径具有条件与限制，具体规则按原作核对 |
| 非凡物品与封印物 | 效果、代价、使用条件和封印方式共同影响玩家选择 |
| 恩赐体系 | 与魔药获取方式分开考虑；施予来源、限制及多种能力并存的条件需核对第二部 |

以上是开发摘要。原作规则、社区推断和项目改编要区分；伤害、冷却、掉落率、消化进度等数值属于游戏设计。

## 资料入口与整理方式

主要入口是用户提供的[灰机 Wiki](https://lom.huijiwiki.com/wiki/首页)，重点查阅[非凡途径](https://lom.huijiwiki.com/wiki/非凡途径)、[占卜家途径](https://lom.huijiwiki.com/wiki/占卜家途径)、[猎人途径](https://lom.huijiwiki.com/wiki/猎人途径)。官方补充参考[诡秘世界官网](https://www.lotmworld.com/zh)；必要时通过 Wiki 脚注回查原作。

每次开发一个具体内容，只记录：**名称和序列、能力与限制、配方或获取方式、扮演与晋升条件、来源、游戏中的改编**。不清楚的内容标为待核，不先填猜测。

前次调研中灰机部分页面直接访问返回 403，读取的是搜索索引；其首页提示多数条目以第一部为基础，第二部尚未全面更新。因此当前资料是起始摘要，完整技能、配方和第二部细则仍需按开发需求核对。
